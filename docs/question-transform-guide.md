# 영어 문제 변형 기능 가이드

## 1. 기능 개요

영어 지문/문제를 입력받아 AI(GPT)를 활용하여 난이도별로 변형 문제를 생성하는 기능입니다.

### 입력 방식
- **이미지 업로드**: JPG, PNG (Vision API 사용)
- **PDF 업로드**: 텍스트 추출 후 처리
- **텍스트 직접 입력**: 지문/문제 붙여넣기

### 출력
- 분석 결과 (원본 문제 유형, 핵심 내용, 주요 어휘)
- 변형 문제 2~3개 (선택한 난이도에 맞는 유형)
- 각 문제별 정답 및 해설

---

## 2. 난이도별 문제 유형

수능 영어 실제 난이도 체계를 기반으로 설계했습니다.

### 상 (고난이도) - 킬러 문항
| 문제 유형 | 설명 | 예시 질문 |
|----------|------|----------|
| **빈칸 추론** | 지문의 핵심 문장을 빈칸으로 | "다음 빈칸에 들어갈 말로 가장 적절한 것은?" |
| **문장 삽입** | 주어진 문장이 들어갈 위치 | "주어진 문장이 들어가기에 가장 적절한 곳은?" |
| **글의 순서** | 문단 순서 배열 | "주어진 글 다음에 이어질 글의 순서로..." |
| **함축 의미** | 밑줄 친 부분의 의미 추론 | "밑줄 친 부분이 의미하는 바로 가장 적절한 것은?" |
| **어휘 적절성** | 문맥상 어휘의 적절성 | "밑줄 친 (A), (B)에 들어갈 말로 적절한 것은?" |

### 중 (중간 난이도) - 표준 문항
| 문제 유형 | 설명 | 예시 질문 |
|----------|------|----------|
| **주제 파악** | 글의 주제 찾기 | "다음 글의 주제로 가장 적절한 것은?" |
| **요지 파악** | 글의 요지 찾기 | "다음 글의 요지로 가장 적절한 것은?" |
| **제목 선택** | 적절한 제목 찾기 | "다음 글의 제목으로 가장 적절한 것은?" |
| **내용 일치** | 내용과 일치 여부 | "다음 글의 내용과 일치하는 것은?" |
| **글의 목적** | 글쓴이의 목적 | "다음 글의 목적으로 가장 적절한 것은?" |

### 하 (기본 난이도) - 기초 문항
| 문제 유형 | 설명 | 예시 질문 |
|----------|------|----------|
| **목적/분위기** | 글의 목적이나 분위기 | "다음 글의 분위기로 가장 적절한 것은?" |
| **지칭 대상** | 대명사가 가리키는 것 | "밑줄 친 they가 가리키는 것은?" |
| **직접 확인** | 명시적 내용 확인 | "다음 글에서 언급된 것은?" |
| **단순 어휘** | 기본 어휘 의미 | "밑줄 친 단어의 의미로 적절한 것은?" |

## 3. 언어 설정 옵션

사용자가 직접 선택할 수 있는 언어 옵션:

| 항목 | 옵션 | 설명 |
|------|------|------|
| **지문** | 영어 (고정) | 항상 영어 원문 유지 |
| **질문** | 한글 / 영어 | 문제 질문의 언어 |
| **선택지** | 한글 / 영어 | 보기의 언어 |

### 일반적인 수능 형식
- 질문: 한글 (예: "다음 글의 주제로 가장 적절한 것은?")
- 지문: 영어
- 선택지: 문제 유형에 따라 다름
  - 어휘/표현 문제 → 영어
  - 주제/제목/요지 문제 → 한글
  - 내용 일치 문제 → 한글

## 4. AI 프롬프트 구조

### System Prompt (시스템 지시)
```
You are an expert in creating Korean 수능 (CSAT) style English test questions.

IMPORTANT RULES:
1. 질문(Question)은 반드시 {선택한 언어}로 작성
2. 선택지(Choices)는 반드시 {선택한 언어}로 작성
3. 지문은 변형 문제에서 반복하지 마세요
4. 각 변형 문제는 서로 다른 유형이어야 함
```

### User Prompt (사용자 요청)
```
다음 영어 지문/문제를 분석하고, [{난이도}] 난이도로 2~3개의 변형 문제를 만들어주세요.

형식:
- 질문은 {언어}
- 지문은 영어 유지
- 선택지는 {언어}

원본:
{원본 지문/문제}
```

### 난이도별 세부 지시
```
상 (고난이도) - 다음 유형으로 변형:
- 빈칸 추론 (지문 중간의 핵심 문장을 빈칸으로)
- 문장 삽입 (주어진 문장이 들어갈 위치 찾기)
- 글의 순서 배열
- 밑줄 친 부분의 함축적 의미 추론
- 문맥상 어휘의 적절성 판단
```

## 5. 출력 형식 예시

### 분석 결과
```
[분석]
- 원본 문제 유형: 제목 찾기
- 핵심 내용: 문화 엔터테인먼트의 경제적 이점과 상업화로 인한 동질화 위험
- 주요 어휘: culturtainment, homogeneous, dilution, exploitation
- 원본 난이도: 중
```

### 변형 문제 (상 난이도)
```
[변형 문제 1] - 빈칸 추론
다음 빈칸에 들어갈 말로 가장 적절한 것은?

The economic benefit of culturtainment makes it attractive to politicians
and policy makers alike. However, such commercialization risks culturtainment
becoming ______________ and losing its original 'message'.

① diversified and innovative
② homogeneous and diluted
③ profitable and sustainable
④ independent and authentic
⑤ competitive and dynamic

정답: ②
해설: 상업화로 인해 문화 엔터테인먼트가 획일화(homogeneous)되고
본래의 메시지가 희석(diluted)될 수 있다는 내용이 지문의 핵심입니다.
```

## 6. 현재 한계점 및 개선 방향

### 현재 한계점
1. **난이도 일관성**: AI가 항상 정확한 난이도로 생성하지 않을 수 있음
2. **문제 유형 다양성**: 같은 유형이 반복될 수 있음
3. **정답 정확성**: AI 생성 정답의 검증 필요
4. **지문 변형**: 빈칸/순서 문제에서 지문 변형이 부자연스러울 수 있음

### 향후 개선 방향
1. **Few-shot 예시 추가**: 각 난이도별 좋은 예시를 프롬프트에 포함
2. **문제 유형 강제 지정**: 사용자가 원하는 문제 유형 직접 선택
3. **검수 단계 추가**: 생성된 문제의 품질 검토 기능
4. **난이도 미세 조정**: 상/중/하 외에 세부 난이도 옵션
5. **오답 근거 제공**: 각 오답이 왜 틀린지 해설 추가
